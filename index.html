什么是智能体技能？.

Agent Skills (智能体技能) 是通过一组精确的指令集，赋能您的 AI 编程助手。以 SKILL.md 文件形式流转，打造可复用的工作流体系。

01

共享基础架构

所有技能底层基于简单的 `YAML Frontmatter + Markdown` 构建。定义 name 和 description，剩下的只需描述给 AI 听即可。这代表着技能天生具备极高的跨平台兼容性。

02

自动化复杂流

摆脱机械劳动：你可以定义一个技能来自动基于 git 历史提炼专业的 Release Notes，或者按照贵公司的代码规范自动化执行 PR Review。

03

无缝集成外部世界

除了内联脚本外，它还允许通过指令对接如 Linear、Notion 或其他运维工具。彻底打碎代码编辑阶段与 DevOps 的无形壁垒。

04

全局与本地多轨存储

支持通过 -g 参数全局安装您的珍藏技能。或者在项目目录生成 ./.agents/skills/ 结构随源码分发，确保团队内部智能体的步调永远一致。

Command Line Core

掌握技能指令矩阵

快速构建和调试您的终端技能网络。

npx skills add <src> [options]

从远程或本地源解析并安装技能。使用 -a, --agent 标记指定生效的代理程序，使用 -g 设置为全局安装。

npx skills list

穿透目录结构，检查当前已经生效的所有挂载技能节点。

npx skills find [query]

触发交互式、高度特化的 fzf 模糊搜索引擎来探测技能仓库。

npx skills init [name]

迅速在当前目录建立标准的 SKILL.md 蓝图模板。您只需填充思想。

协议注入源解析

底层架构支持直接解析并拉取多种形态的代码存储源，自动扫描结构化 SKILL 文件：

GitHub 极速通道形式
npx skills add vercel-labs/agent-skills
指定标准 Git 库地址
npx skills add git@github.com:vercel-labs/agent-skills.git
深层子树寻址
npx skills add https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines
离线本地挂载路径
npx skills add ./my-local-skills
