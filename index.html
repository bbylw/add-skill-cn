核心多态解析引擎 (Polymorphic Sources)

支持直接从本地系统绝对路径、远端 GitHub 注册表短链或非标准目录深层树结构分发技能。 CLI 内置引擎将对 Git 架构自动进行拓扑解析。

仓库短链解析 [EXEC]

skills add owner/repo

远程目录剥离 [EXEC]

skills add https://../tree/main/sub

强制隔离作用域

执行层建立沙盒机制，严格隔离 项目级 (Project) 依赖树与 系统全局级 (Global) 越权应用映射。

局部工作区 ./<agent>/skills/
全系统覆写 [-g] ~/<agent>/skills/

# 高维代码审查协议系统

您的任务是作为一名资深前端架构师审核提交的代码。

## 审核准则
1. 检查是否存在硬编码的色值。
2. 识别并标记三层以上的嵌套 map。
3. 确保所有的 Lucide 图标都正确导入。

系统环境变量_门限控制

INSTALL_INTERNAL_SKILLS DEF: 0

强行解除非稳态包拦截器保护。设置为 1 以开启内部测试技能的安装支持。

DISABLE_TELEMETRY / DO_NOT_TRACK DEF: 0

彻底终止并掐断底层异步使用指标回传链路。Agent Skills 始终尊重用户的隐私安全。

异常诊断_日志 (FAQ)

ERR: NO_SKILL_LOCATED

确保仓库根目录下包含 SKILL.md 文件，且 YAML Frontmatter 格式完全正确。

ERR: PERMISSION_DENIED

全局模式安装可能需要系统管理员权限。请调整 ~/.npm-global 权限或使用提权进程。
